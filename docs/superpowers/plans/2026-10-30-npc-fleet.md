# NPC Fleet Implementation Plan

> For agentic workers: implement independent model families and gameplay in parallel, then integrate and review.

**Goal:** More varied and realistic NPC vehicles, with substantially richer road traffic.
**Architecture:** Shared catalogue and bounds, separate passenger and commercial geometry builders, renderer templates/paint variants, progressive simulation population.
**Tech Stack:** Existing TypeScript, Three.js and Node test runner.
**Spec:** ../specs/2026-10-30-npc-fleet-design.md

## Constraints

Keep player models/showroom unchanged. All NPCs remain grounded. Flying barricades retain their behavior. Use conventional commit slices. Reuse code-generated geometry; no new downloads or runtime dependencies.

## Review focus

Real geometry matching collider dimensions, heavy-vehicle headway and safe lane-change timing, spawn/reward clearance, finite traffic/pool counts, independent lights/wheel animation and restart determinism.
